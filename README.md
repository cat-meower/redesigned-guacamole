# redesigned-guacamole

A tiny static website that takes the name **redesigned-guacamole** way too seriously.

## What is it?

A playful landing page + interactive guacamole lab built with plain HTML, CSS, and JavaScript. No framework or build step required.

## GitHub Pages

This repository is designed to work as a GitHub Pages site. The entry point is `index.html`.

## Features

- Responsive dark/glowy landing page
- Interactive spice slider
- Random guacamole remix button
- Guacamole generator and intensity meter
- Tiny secret mode

Made for the fun of it. 🥑
